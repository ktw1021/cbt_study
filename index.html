CBT 빈칸 학습

이름 + 4자리 비밀번호로 시작합니다. 데이터는 이 브라우저에만 저장됩니다.

로그인
  1. 위에 가입할 때 쓴 이름 입력
  2. 4자리 비밀번호 입력 후 로그인
회원가입
  1. 위에 이름 입력 (2자 이상)
  2. 4자리 숫자 비밀번호 + 확인
  3. 「계정 만들기」 → 저장 후 자동 로그인

계정·카드는 이 브라우저 IndexedDB에 저장됩니다. 백업은 사이드바 내보내기/가져오기(JSON)를 사용하세요.
