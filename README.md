# CBT 빈칸 학습 앱

긴 법률·시험 원문을 **빈칸 채우기**로 외우기 위한 웹 앱입니다.  
인터넷 서버에 올리는 방식이 아니라, **지금 쓰는 브라우저(노트북·PC) 안**에 카드와 학습 기록이 저장됩니다.

---

## 처음 쓰는 방법

1. 앱을 브라우저에서 연다 (아래 **실행 방법** 참고).
2. **이름 + 4자리 숫자 비밀번호**로 회원가입하거나, 기존 계정으로 로그인한다.
3. **카드관리**에서 폴더·카드를 보거나, **카드제작**에서 새 카드를 만든다.
4. **학습모드**에서 학습 방식을 고른 뒤 **학습 시작** → 문제를 보면서 해설 빈칸에 답을 넣고 채점한다.

---

## 실행 방법

브라우저 주소창에 `file://`로 HTML 파일만 여는 방식은 동작이 불안정할 수 있다. **로컬 서버**로 여는 것을 권장한다.

```bash
cd cbt_blank_study_app
npm run dev
```

터미널에 나온 주소(기본 `http://127.0.0.1:5173`)로 접속한다.  
CSS·JS를 수정하면 **자동 새로고침**된다.

---

## 로그인 / 계정

- **회원가입:** 이름 + 4자리 숫자 비밀번호(0000~9999).
- **로그인:** 같은 브라우저에 저장된 계정 목록에서 고른 뒤 비밀번호 입력.
- **새로고침**해도 같은 브라우저면 로그인 상태가 유지되는 경우가 많다(세션 저장).
- 계정·카드 데이터는 **이 PC·이 브라우저**에만 있다. 다른 기기·다른 브라우저와는 **자동으로 공유되지 않는다**.
- 옮기려면 사이드바 **전체/유저/폴더 내보내기** JSON 파일을 쓰고, **가져오기**로 불러온다.

---

## 카드 만들기

카드는 **문제**와 **해설** 두 덩어리로 나뉜다.

| 구분 | 내용 |
|------|------|
| **문제** | 시험에 나올 법조문·지문 등 (빈칸 없음) |
| **해설** | 암기할 문장. 여기만 **빈칸**을 만든다 |

**카드제작** 흐름:

1. 제목·폴더 입력.
2. **문제** 칸에 문제 텍스트 입력.
3. **해설** 칸에 암기 문장 입력 → 외울 단어를 드래그 → **Ctrl+B** (또는 「선택 → 빈칸」).
4. 아래 **정답 칸**에 빈칸별 정답 입력 (동의어는 줄바꿈 또는 `||`로 구분).
5. **저장**.

빈칸은 **추천 5개**, **후보 고르기** 등으로 자동 생성할 수도 있다.  
제작 화면 미리보기에서는 빈칸이 `○○○` 모양으로 보인다.

---

## 카드 관리

- **폴더** 트리로 카드를 분류한다.
- 카드를 드래그해서 다른 폴더로 옮길 수 있다.
- 카드 선택·플래그(색)·검색·필터로 학습 대상을 고른다.
- 상세 화면에서 카드 내용을 수정할 수 있다.

---

## 학습하기

**학습모드** → 방식 선택(전체 순서, 랜덤, 선택 카드, 최근 오답 등) → **학습 시작**.

| 화면 | 역할 |
|------|------|
| **왼쪽** | **문제** (빈칸 없음). 스크롤 따로 |
| **오른쪽** | **해설** — 문장 안에 빈칸 입력. 스크롤 따로 |
| **해설 위** | `빈칸 1`, `빈칸 2` … 버튼 (가로 스크롤). 누르면 해당 빈칸으로 이동 |
| **아래** | 채점 결과, 메모, **전체 채점** / **다시 풀기** |

- 빈칸에 답 입력 후 **Enter** → 그 빈칸만 채점.
- **전체 채점** → 모든 빈칸 한 번에 채점.
- **유사도** 슬라이더로 오타 허용 정도 조절 (기본 80% 근처).
- **실제 문제 풀 때만** 사이드바가 자동으로 접힌다. 카드 제작·관리에서는 접히지 않는다.
- 학습 중 **새로고침**해도, 마지막에 학습하던 카드 목록·순서는 **이어서** 복구된다. (카드관리·카드제작 화면으로 나가면 학습 큐는 초기화된다.)

### 회독

- **회독** 숫자는 **자동으로 올라가지 않는다**.
- **회독 +1 / -1** 버튼으로 직접 조절하는 메모용 카운터다.
- 채점하면 **최근 정답/오답**(`lastResult`)과 **오답 횟수** 등은 카드에 기록된다.

## 무엇이 저장되고, 무엇은 안 되나

데이터는 브라우저 **IndexedDB**(`cbt_blank_study_v1`)에 저장된다. 같은 기기·같은 브라우저를 지우지 않는 한 유지된다.

| 저장됨 | 저장 안 됨 |
|--------|------------|
| 카드 저장·수정·삭제 | 채점 **전**에만 칸에 적어 둔 글 (Enter/전체 채점 전) |
| 빈칸 채점 결과, 빈칸별 마지막 입력 | 되돌리기(Undo) **기록** — 새로고침하면 사라짐 |
| **메모 저장** 버튼으로 저장한 메모 | |
| 회독 ±, 플래그, 폴더 구조 | |
| JSON 내보내기 파일 (백업용) | |

**메모 저장**을 누르면 아래 안내 칸에 「메모 저장됐습니다.»가 뜬다.

---

## 되돌리기 (Undo)

**된다.** 다만 범위를 알고 쓰는 것이 좋다.

- 사이드바 **되돌리기** 또는 **Ctrl+Alt+Z**
- 카드·폴더·채점·메모 저장·가져오기 등 **데이터를 바꾸기 직전** 상태로 최대 **60단계**까지 되돌릴 수 있다.
- **같은 탭을 연 상태**에서만 유효하다. **페이지를 새로고침하거나 닫으면** 되돌리기 목록은 **사라진다**.
- 텍스트 입력 중 **Ctrl+Z**(글자 하나 취소)와는 별개다.

되돌릴 게 없으면 「되돌릴 상태가 없습니다.» 알림이 뜬다.

## 단축키

| 키 | 동작 |
|----|------|
| **Ctrl+B** | 해설에서 선택한 글 → 빈칸 (카드 제작·학습 중 수정) |
| **Enter** | 학습 중 — 해당 빈칸 채점 |
| **Ctrl+Alt+Z** | 앱 데이터 되돌리기 |
| **Ctrl+1~7** | 플래그 색 / **Ctrl+0** 플래그 해제 |

---

## 백업

- **전체 내보내기** — 앱 데이터 통째로 JSON
- **유저 내보내기** — 로그인한 사용자 데이터만
- **폴더 내보내기** — 선택 폴더만
- **가져오기** — JSON 파일 (병합 또는 덮어쓰기 선택)

## 기술 메모 (개발용)

```
cbt_blank_study_app/
├── index.html
├── css/          variables, layout, components
├── js/
│   ├── main.js   진입·이벤트
│   ├── core/     store, IndexedDB
│   ├── domain/   카드·빈칸·쿼리
│   ├── services/ undo, 채점, import/export
│   ├── ui/       화면·렌더
│   └── app/      actions.js — 버튼·저장·학습 로직
└── package.json  npm run dev
```

정식 실행은 `index.html` + ES 모듈(`js/main.js`)이다. `js/app.bundle.js`는 번들 빌드 산출물이며, 일반 사용 시 `npm run dev` + 모듈 방식을 쓰면 된다.
